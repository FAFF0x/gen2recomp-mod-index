# Free Max Repel - Gen 2

Adds **MAX REPEL** to every standard Poké Mart in Pokémon Recomp Gen 2.

- Buy price: **0**
- Only standard Poké Marts are modified.
- Specialty shops are left untouched.
- Uses the native Gen 2 MartMenu, so Modern UI can continue to present the shop normally.
- Gen 2 only.
