# Example Mod

One or two sentences on what the mod actually does. The first ordinary line
becomes the card blurb if `summary` is empty, so make it count.

## What it changes

- The concrete list. Species stats, a new map, a UI screen — whatever you touch.
- If you ship a `DIFFERENCES.md`, this is the short version of it.

## Install

1. Download `example_mod-1.0.0.zip` from the releases page.
2. In the launcher, MODS → **Import mod .zip**.
3. Enable it and start a new game (or load a save — migrations run on load).

With `github` set in the manifest, the launcher's **Update** and **Versions**
buttons take over from here.

## Compatibility

- Mod API 2, engine `>=0.9`.
- Pure `content` profile: link play is unaffected.
- No known conflicts.
