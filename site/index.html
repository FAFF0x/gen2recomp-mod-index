1 · GitHub

Signed out. A submission is a pull request, so it needs your account.

A fine-grained token needs Contents: read&write and Pull requests: read&write on your fork of this index, or use a classic token with public_repo. It is kept in this tab only (sessionStorage), sent straight to api.github.com, and never stored or proxied by this page.

2 · Description

Becomes description.md. Required. Keep it under 64 KB.

4 · Where it downloads from

Set github and the launcher's Update and Versions buttons work: it reads that repo's Releases and installs the newest <id>-<version>.zip. The index re-checks nightly, so you do not open a PR per version bump.

5 · Engine fit

Leave unchecked for a pure content mod. Overhauls and conversions normally check it.
